# LinkedIn Content Machine Workflow

1. **Capture** — Drop raw ideas into the original folders or a new note.
2. **Extract** — Copy a polished version into `drafts/` with frontmatter (never delete the original).
3. **Improve** — Edit for LinkedIn format (hook, short paragraphs, CTA).
4. **Add assets** — Place images in `images/` and reference them.
5. **Mark ready** — Move or copy to `ready/` and update calendar.
6. **Schedule** — Set target_date.
7. **Publish** — Post on LinkedIn, then move status to published and add the URL.
8. **Review weekly** — Use calendar.md to keep the pipeline moving.

This structure turns the existing uncompleted material into a repeatable system without losing anything that was already written.
