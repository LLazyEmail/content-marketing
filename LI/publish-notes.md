# Publish Notes

When a post folder is ready:

1. Open `post.md` and copy the final text.
2. Upload the images from the `images/` folder together with the post.
3. Publish on LinkedIn.
4. Add the live link as a new row in `published.md`.
5. Update the row in `status-tracker.md` (or remove it from `queue.md`).
6. Change `LI/next.md` to the next unfinished post.

Keep the original large files and the big image dump untouched.
