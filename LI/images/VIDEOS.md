# Social-media videos (Dropbox)

Videos from the Dropbox folder [`/13 social-media`](https://www.dropbox.com/home/13%20social-media) are inventoried here instead of being stored in git.

GitHub rejects or struggles with large uploads, and the MP4s in this folder total **1.58 GiB**. Photos and a few smaller videos are already in [`LI/images/`](./), which mirrors the Dropbox folder layout. The rest stay in Dropbox, with a share link for each file.

## Share-link access

Each link below was created as a **view-only, download-enabled** Dropbox link, with no password and no expiry. The Dropbox connector cannot create public “anyone with the link” URLs, so these links currently have audience **restricted** (`no_one`): they work for people who already have access to the files. They will not work for a random visitor of this repository.

To make a link public, open it in the Dropbox web UI and change the access setting to “anyone with the link”. You can also revoke a link from the same UI: <https://help.dropbox.com/share/unshare-folder>.

## Why these files are not all in git

The largest file is `H -/VID_20250913_141444.mp4` at 363.9 MiB, and several others are well over GitHub’s recommended 50 MiB / hard 100 MiB limits. Git LFS is not enabled on this repository and is not being added here. Smaller videos that were already committed under `LI/images/` stay in git; new `.mp4` and `.mov` files are ignored (see the root `.gitignore`) so they are not added by accident. Use the share links above, or the Dropbox folder, when you need the full-quality files.
