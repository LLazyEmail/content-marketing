# Image Naming Convention

When moving images from Dropbox into `LI/images/`:

- Use lowercase and hyphens: `01-bakhmut-road-burned-vehicle.jpg`
- Prefix with the post number or short slug when possible
- Keep original filenames as a comment in the post if useful
- Prefer JPG/PNG; avoid spaces and special characters

Example references in a post:
```markdown
![Burned vehicles along the road](images/01-bakhmut-road-burned-vehicle.jpg)
```

This makes the content machine self-contained.
