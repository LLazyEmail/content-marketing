# Images for LinkedIn Posts

Place images that belong with LinkedIn posts here so everything lives together in the repository.

## Suggested Approach

1. Create subfolders or use clear filenames: `01-bakhmut-road-vehicle.jpg`, `patch-on-sleeve.jpg`, etc.
2. Reference them in the post markdown:
   ```markdown
   ![Description](images/01-bakhmut-road-vehicle.jpg)
   ```
3. Prefer moving (or copying) from Dropbox rather than leaving links that can break.
4. Keep original Dropbox files until the GitHub versions are confirmed.
