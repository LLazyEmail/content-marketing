# Status Guide for LI Content

| Status | Meaning | Action |
|--------|---------|--------|
| idea | Raw note or incomplete | Expand or archive |
| draft | Being written / improved | Finish and move to ready |
| ready | Polished, has frontmatter, images linked if needed | Schedule and publish |
| scheduled | Queued to post (in the scheduler) | No live link yet; track in `scheduled.md` |
| published | Live on LinkedIn | Add URL to `published.md`, keep local copy |
| on-hold | Paused | Review later |

**Never delete.** Move improved versions forward; leave originals in folder A / folder b / folder-A1.

Update both the post frontmatter and the matching tracker (`scheduled.md` or `published.md`) when the status changes.
