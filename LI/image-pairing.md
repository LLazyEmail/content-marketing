# Image Pairing Guide

Stop grabbing images randomly.

## Process

1. Open the post folder you are working on (e.g. `posts/01-bakhmut-road/`).
2. Look at the text in `post.md`.
3. From the big `LI/images/` dump (or the INDEX.md), pick **only** the photos that match that story.
4. Copy them into `posts/01-bakhmut-road/images/`.
5. Reference them at the bottom of `post.md` or just know they are ready to upload with the post.

## Tips

- One post = a small set of images (usually 1–4).
- If you are unsure which image belongs, leave it in the dump and decide later.
- The INDEX.md in `LI/images/` helps you browse, but the real working set lives inside each post folder.

This keeps image selection deliberate instead of random.
