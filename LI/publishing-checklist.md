# LinkedIn Publishing Checklist

Before marking a post as published:

- [ ] Hook is strong in the first 2 lines
- [ ] Frontmatter status = ready and target_date set
- [ ] Images referenced from `images/` if used
- [ ] Hashtags chosen (see hashtags-guide.md)
- [ ] CTA or question at the end
- [ ] Posted on LinkedIn
- [ ] URL added to calendar.md
- [ ] Status updated to published in both frontmatter and calendar
- [ ] Original source file left untouched

This keeps the content machine consistent.
