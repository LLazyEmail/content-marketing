# LI Guides

Rules and skills for working inside the LI folder.

## Skills / Algorithms

- **[skill-mark-published.md](skill-mark-published.md)** — Exact steps to mark a post as **scheduled** (queued, no link yet) or **published** (live, link required). Covers image move, frontmatter, `scheduled.md` / `published.md`, and opening a PR. Use this every time a post is queued or goes live.
- **[skill-rewrite-first-person.md](skill-rewrite-first-person.md)** — Exact steps to rewrite a post so it is told from the author's perspective (first person) and is easier to read. Use this whenever a post should be rewritten from "you" / third person to "I" / "me".

## Other guides

- **[single-post-organization.md](single-post-organization.md)** — Permanent rule for the one-folder-per-post layout (`post.md` + `images/` with `.gitkeep`). Follow this for every new or existing post.
- [image-checklist.md](image-checklist.md) — how to pick images for a post
- [how-to-mark-published.md](how-to-mark-published.md) — short human version of the schedule / publish steps
