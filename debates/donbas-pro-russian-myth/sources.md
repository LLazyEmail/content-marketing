# Sources — Donbas debate notes

Numbered bibliography extracted from the debate notes build script (`build.py` / PDF references).
These notes debunk the narrative that a "pro-Russian Donbas" caused the 2014 occupation.
Inline tags in the PDF/DOCX are `[R#]`; **R26 is not present** in the source list (numbering jumps R25 → R27).

**Rule:** only URLs taken from the original refs are linked. Entries without a clean `http(s)` URL are listed as plain text with a note.
