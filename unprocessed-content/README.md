## Triage Process

1. Review each file weekly.
2. Decide:
   - Promote to `drafts/` + add to calendar
   - Archive if outdated
   - Delete if not useful
3. Add YAML frontmatter once it becomes a real draft.
4. Move supporting assets to `assets/`.

Keep this folder small — it should be an inbox, not a long-term home.
