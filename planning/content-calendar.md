# Content Calendar & Submission Tracker

Use this file (or a linked Google Sheet / Notion) to manage the pipeline from idea → published.

## Status Legend

- `idea` — Concept noted
- `draft` — Writing in progress
- `ready` — Ready for review / polish
- `submitted` — Sent to platform
- `published` — Live
- `scheduled` — Planned for a future date
- `rejected` / `on-hold`

## Platforms

- HackerNoon
- LinkedIn
- Substack / Newsletter
- Indie Hackers
- YC Forum
- Other (blog, Medium, etc.)

### How to update

1. Add a new row for every piece of content.
2. Change status as it moves through the pipeline.
3. Fill target date for scheduling.
4. Link to the local file or published URL.
5. Optionally sync with the Google Sheet mentioned in the original README.

## Weekly Review

- Mondays: Review `idea` and `draft` items.
- Mid-week: Move ready items to `submitted`.
- Fridays: Check published and schedule next week.
