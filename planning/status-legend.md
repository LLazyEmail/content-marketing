# Content Status Legend

Use these consistently in the calendar, frontmatter, and schedule.json.

| Status | Meaning | Next Action |
|--------|---------|-------------|
| idea | Concept only | Expand into draft or archive |
| draft | Actively writing | Finish and move to ready |
| ready | Polished, checklist done | Submit |
| submitted | Sent to platform | Wait for feedback / publish |
| published | Live | Add URL, keep local copy |
| scheduled | Future date set | Remind before date |
| on-hold | Paused | Review later |
| rejected | Not accepted | Archive or revise |

Never delete a file just because status changed — update the tracker instead.
