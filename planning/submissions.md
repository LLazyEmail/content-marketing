# Submission Checklist & Tracker

Easy reference for preparing and submitting content to different platforms.

## General Checklist (before submission)

- [ ] Title is clear and SEO-friendly
- [ ] Intro hooks the reader in first 2 sentences
- [ ] Code samples / images are properly formatted
- [ ] Links work and are relevant
- [ ] Proofread (or run through AI / Grammarly)
- [ ] Frontmatter or metadata updated
- [ ] Added to content-calendar.md

## Platform-Specific

### HackerNoon

- [ ] Follow HN style guide (https://hackernoon.com/writing)
- [ ] Include relevant tags
- [ ] Add author bio link
- [ ] Submit via their editor or pitch if needed
- Target length: 800–2000 words

### LinkedIn

- [ ] Hook in first line (visible before "see more")
- [ ] Use line breaks and emojis sparingly
- [ ] End with question or CTA
- [ ] Tag relevant people/companies if appropriate
- [ ] Schedule via LinkedIn native or Buffer/Hootsuite

### Substack / Newsletter

- [ ] Subject line A/B tested or optimized
- [ ] Preview text set
- [ ] Include unsubscribe and branding
- [ ] Schedule send time (best: Tue–Thu morning)

### Indie Hackers / YC Forum

- [ ] Keep authentic, less polished if needed
- [ ] Focus on lessons learned / data
- [ ] Engage with comments after posting
