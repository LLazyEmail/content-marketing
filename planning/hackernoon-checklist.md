# HackerNoon Submission Checklist

Reference: https://hackernoon.com/writing

## Before Submitting

- [ ] Title is clear, specific, and not clickbaity
- [ ] Strong hook in the first 100 words
- [ ] Proper headings (H2/H3) for scannability
- [ ] Code blocks or images are formatted correctly
- [ ] All links work and open in new tabs where appropriate
- [ ] Author bio is up to date
- [ ] Relevant tags selected
- [ ] Word count roughly 800–2000 (or series length)
- [ ] Proofread (or AI-assisted review)
- [ ] Frontmatter / calendar status updated

## After Submission

- [ ] Note submission date in content-calendar.md
- [ ] Track editor feedback if any
- [ ] Update to `published` once live and add URL

**Rule:** Never delete the local draft after publishing — keep it for reference or move to published/.
