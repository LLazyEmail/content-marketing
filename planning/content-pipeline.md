# Content Pipeline

```
Idea (unprocessed-content/)
    ↓
Draft (drafts/ + frontmatter)
    ↓
Ready (checklist complete)
    ↓
Submitted (platform)
    ↓
Published (published/index.md + URL)
    ↓
Archive (when superseded)
```

Update `planning/content-calendar.md` at every transition.

**Core rule:** Never simply delete existing repository content. Move, index, or archive instead.
